Car & Automotive Hacking

Cyber Club Quick Reference · v1.0

A modern car is a network on wheels: 50–150 electronic control units talking over buses that were designed for reliability, not security. The core bus — CAN — is broadcast, has no source address, and no authentication. If you have read the OT material, this will feel familiar: it is the same story as Modbus, with a steering rack attached. The good news for learning is that you can do almost all of it in software, on a virtual bus, for free.

CAN is the Modbus of the car. Every node hears every frame, any node can send any arbitration ID, and nothing proves who sent what. Security has to come from segmentation and gateways, never from the bus itself.

A CAN frame

The whole format
  • Arbitration ID (11 or 29 bit) — identifies the message, not the sender. Lower ID = higher priority.
  • DLC — data length, 0–8 bytes (64 on CAN-FD).
  • Data — the payload. Meaning is defined per-vehicle in a proprietary DBC database you usually don't have.
  • CRC / ACK — integrity against noise, not against an attacker.

Typical candump line:
can0 18A [8] 00 1C 00 00 00 00 00 7D

Why there's no authentication

1986 design
  • Designed for a closed, trusted set of nodes inside one vehicle.
  • Hard real-time budgets — crypto costs microseconds nobody allocated.
  • 8-byte payloads leave no room for a MAC.
  • Any node can spoof any ID, and a flood of ID 0x000 wins arbitration forever — a trivial bus DoS.
  • Mitigations are bolted on: gateway ECUs segmenting buses, message counters, AUTOSAR SecOC, and intrusion detection on the bus.

Buses and protocols

Bus / protocolWhere it's usedSecurityNotes
CAN / CAN-FDPowertrain, chassis, body — the backbone None Broadcast, no source identity. CAN-FD raises payload to 64 bytes and speeds up, but adds no authentication
LINCheap peripherals: mirrors, seats, wipersNone Single-wire, low speed, master/slave. Often reachable from a door module
FlexRayHigh-end chassis, x-by-wireNone Deterministic and time-triggered; harder to inject into because of the schedule
Automotive Ethernet + SOME/IPADAS, cameras, infotainment backbone Varies Where the industry is heading. Normal IP tooling applies — and normal IP flaws
OBD-IIMandatory diagnostic port, driver's footwell Physical access = bus access Standard PIDs (Mode 01) expose RPM, speed, coolant. Legally required to exist
UDS (ISO 14229)Diagnostics & reprogramming Seed/key, often weak The powerful one — see services below. Weak seed/key algorithms are a classic finding
ISO-TP (ISO 15765-2)Transport over CANNone Segments messages longer than 8 bytes; UDS rides on it
J1939Trucks, buses, heavy equipmentNone CAN-based but standardised payloads — one DBC fits many vehicles, unlike cars

Attack surface map

Remote → local
  • Telematics / TCU — cellular-connected. The only truly remote entry point, and the one that made the Jeep hack famous.
  • Infotainment — Linux/Android, Bluetooth, Wi-Fi, USB, media parsers. Big attack surface, often bridged to CAN through a gateway.
  • Keyless entry (RKE/PKE) — rolling-code replay, and relay attacks that extend the key's range from inside the house.
  • TPMS — unauthenticated 315/433 MHz sensor broadcasts; trackable and spoofable.
  • OBD-II dongles — insurance and fleet devices put a cellular radio directly on the bus.
  • EV charging — OCPP backends and ISO 15118 plug-and-charge.
  • Direct wiring — 2023 thefts injected CAN frames via headlight wiring to spoof "key present" to the door module.

Tooling

Software

Mostly free
  • can-utils (Linux) — the core kit:
    candump can0 capture · cansend can0 123#DEADBEEF inject · cansniffer highlights changing bytes · cangen fuzz · canplayer replay
  • SocketCAN — CAN as a Linux network interface. Create a virtual bus with modprobe vcan and ip link add dev vcan0 type vcan.
  • SavvyCAN — GUI capture, DBC decoding, diffing.
  • python-can / udsoncan / scapy (automotive layers) — scripting.
  • Wireshark — dissects SocketCAN and ISO-TP captures natively.
  • caringcaribou — discovery of UDS services and seed/key probing.

Hardware & labs

When you go physical
  • CANable / CANtact / USB2CAN (~$30–60) — USB-to-CAN, SocketCAN-native.
  • ValueCAN / Kvaser / PCAN — professional interfaces.
  • ICSim — the instrument-cluster simulator. A fake dashboard on a virtual bus; the standard way to learn without a car.
  • Bench ECU — a junkyard ECU, 12 V supply and a CAN interface is the safest real hardware.
  • Logic analyser / oscilloscope — for physical-layer and wiring work.
  • CARLA — full driving simulation for ADAS-level research.

A first lab, start to finish

No car required
  1. Create a virtual bus: sudo modprobe vcan then sudo ip link add dev vcan0 type vcan && sudo ip link set up vcan0.
  2. Run ICSim against vcan0 — you get a dashboard and a controller.
  3. candump vcan0 and watch the noise.
  4. Use cansniffer vcan0, press a control, and see which bytes change.
  5. Isolate the arbitration ID for speed, then cansend a forged frame and watch the needle move.
  6. Replay a capture with canplayer to understand why replay alone is detectable.

That loop — capture, diff, isolate, forge — is the whole discipline in miniature.

Safety & legality

Read before touching a car
  • Only your own vehicle, or one you have written permission to test. Unauthorised access to a vehicle's systems is a computer crime.
  • Never inject on a moving vehicle, and never with anyone inside. Bus faults can disable steering assist, brakes or the engine.
  • Test on a bench ECU or simulator first — always.
  • Writing to ECUs can brick them, void warranty, or leave a car un-startable. Flashing is irreversible without the original image.
  • Never transmit on key-fob frequencies without understanding local RF law.
  • Disclose responsibly — the Auto-ISAC and most manufacturers run coordinated disclosure programmes.

Incidents worth knowing

  • Jeep Cherokee (Miller & Valasek, 2015) — remote compromise via the Uconnect cellular head unit, pivoting to CAN to control brakes and steering. Triggered a 1.4M-vehicle recall and effectively created the industry.
  • CAN injection thefts (2023) — thieves spliced into headlight wiring to inject frames spoofing "valid key", unlocking and starting vehicles in under a minute.
  • Relay attacks — two radios extend a passive key's range from inside a house to the driveway. Still widespread; mitigated by UWB distance bounding.
  • Tesla at Pwn2Own — repeated infotainment and gateway compromises, but notable for fast OTA remediation — the counter-example that updates can work.
  • BMW ConnectedDrive (2015) — unauthenticated telematics commands could unlock doors; fixed over the air.
